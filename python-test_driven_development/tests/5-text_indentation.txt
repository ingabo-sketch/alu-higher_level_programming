Doctest for text indentation
=============================

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Print two blank lines after the separators:

    >>> text_indentation("Hello. World? Yes: done")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
    Yes:
    <BLANKLINE>
    done

Strip spaces around each printed line:

    >>> text_indentation("  Hi.   There")
    Hi.
    <BLANKLINE>
    There

Reject a value that is not a string:

    >>> text_indentation(12)
    Traceback (most recent call last):
    TypeError: text must be a string

    >>> text_indentation(None)
    Traceback (most recent call last):
    TypeError: text must be a string
